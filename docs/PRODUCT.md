# Product: MCP Marketplace

## What it is

Claude Code plugin marketplace listing local-first MCP servers (security, database, OpenAPI, dependencies, LLM cost, SEO, dealfinder).

## What it is NOT

- Not an npm registry and not a hosted MCP gateway.
- Not a substitute for each server’s own repository docs.

## Users

Claude Code users installing the marketplace; also a discovery landing page for the suite.

## Pricing

Plugins themselves are free for local stdio use; individual servers may offer separate paid/hosted plans in their own products.
