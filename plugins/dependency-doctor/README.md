# Dependency Doctor (Claude Code plugin)

Read-only npm dependency inventory, audit and health diagnostics.

This plugin starts the [mcp-dependency-doctor](https://github.com/petrovicistefan/mcp-dependency-doctor) MCP server over stdio via `npx -y mcp-dependency-doctor`. Nothing is sent anywhere: it runs locally and needs no account or API key.

See the [project README](https://github.com/petrovicistefan/mcp-dependency-doctor#readme) for tools and usage.
