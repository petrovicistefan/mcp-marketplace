# SEO Auditor (Claude Code plugin)

Read-only static SEO audits and bounded crawling, running locally.

This plugin starts the [mcp-seo-auditor](https://github.com/petrovicistefan/mcp-seo-auditor) MCP server over stdio via `npx -y mcp-seo-auditor`. Nothing is sent anywhere: it runs locally and needs no account or API key.

See the [project README](https://github.com/petrovicistefan/mcp-seo-auditor#readme) for tools and usage.
