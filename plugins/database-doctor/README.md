# Database Doctor (Claude Code plugin)

Offline PostgreSQL diagnostics: SQL review, risky migrations, index candidates, EXPLAIN plans.

This plugin starts the [mcp-database-doctor](https://github.com/petrovicistefan/mcp-database-doctor) MCP server over stdio via `npx -y mcp-database-doctor`. Nothing is sent anywhere: it runs locally and needs no account or API key.

See the [project README](https://github.com/petrovicistefan/mcp-database-doctor#readme) for tools and usage.
