# Cost Optimizer (Claude Code plugin)

Local-first LLM cost analysis and model-switch savings estimates.

This plugin starts the [mcp-cost-optimizer](https://github.com/petrovicistefan/mcp-cost-optimizer) MCP server over stdio via `npx -y mcp-cost-optimizer`. Nothing is sent anywhere: it runs locally and needs no account or API key.

See the [project README](https://github.com/petrovicistefan/mcp-cost-optimizer#readme) for tools and usage.
