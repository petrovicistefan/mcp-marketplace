# API Guardian (Claude Code plugin)

Local OpenAPI contract checks and breaking-change detection for AI coding agents.

This plugin starts the [mcp-api-guardian](https://github.com/petrovicistefan/mcp-api-guardian) MCP server over stdio via `npx -y mcp-api-guardian`. Nothing is sent anywhere: it runs locally and needs no account or API key.

See the [project README](https://github.com/petrovicistefan/mcp-api-guardian#readme) for tools and usage.
